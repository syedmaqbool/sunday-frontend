# Triage labels

| Role in engineering skills | Label in this repo | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the ticket. |
| `needs-info` | `needs-info` | The ticket needs more information from its reporter. |
| `ready-for-agent` | `ready-for-agent` | The ticket is fully specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | The ticket requires a human implementer. |
| `wontfix` | `wontfix` | The ticket will not be actioned. |
